# abdulaziz  Store - Angular Ecommerce Project

This project was written from scratch to match the ecommerce assignment requirements.

## What it includes
- Store name in the header
- Search box
- Cart button
- 14 products
- 6 product categories
- Product cards with name, description, stock status and price
- Left-side category navigation
- Category filtering
- Live product search
- Responsive product grid
- Vercel configuration

## Run the project
1. Install Node.js LTS.
2. Extract this ZIP and open the project folder in VS Code.
3. Open Terminal in VS Code.
4. Run: `npm install`
5. Run: `npm start`
6. Open `http://localhost:4200`

## GitHub
Create a NEW PUBLIC repository, for example `yashal-angular-ecommerce`.

Then run:
`git init`
`git add .`
`git commit -m "Initial Angular ecommerce project"`
`git branch -M main`
`git remote add origin https://github.com/YOUR-USERNAME/yashal-angular-ecommerce.git`
`git push -u origin main`

## Vercel
1. Sign in to Vercel.
2. Select Add New > Project.
3. Import the GitHub repository.
4. Framework: Angular.
5. Build command: `npm run build`
6. Output directory: `dist/yashal-angular-ecommerce/browser`
7. Deploy.
8. Test the live page.
9. Copy the public Vercel URL.
